# Robot Mopping Floor

This project is an automatic floor-mopping robot based on ESP32/Arduino. 
The robot can move, clean the floor using a mopping mechanism, and use camera-based object detection.

## Main Features
- Motor control
- Floor cleaning mechanism
- Servo movement
- ESP32-CAM video streaming
- YOLO object detection
- Obstacle/object detection response

## Files
- robot_mopping_main.ino — main robot control code
- esp32_cam_stream.ino — ESP32-CAM video streaming code
- esp32cam_yolo_detection.py — Python YOLO object detection code
